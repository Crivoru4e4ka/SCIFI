## 🎮 Как использовать Kanban доску

### Просмотр доски
1. Откройте раздел (проект)
2. Выберите вкладку **"Доска"**
3. Вы увидите три колонки с задачами

### Перемещение задачи между состояниями
**Способ 1: Drag-and-Drop (рекомендуется)**
```
1. Наведите мышь на карточку задачи
2. Нажмите и удерживайте левую кнопку мыши (курсор изменится на "grab")
3. Перетащите задачу в нужную колонку
4. Отпустите кнопку мыши
5. Статус задачи обновится автоматически
```

**Способ 2: Через форму создания задачи**
```
1. Создайте задачу с нужным статусом в модальном окне
2. Выберите нужный статус при создании
```

## 🔄 Как это работает технически

### Backend (Go)
```go
// При перемещении задачи отправляется запрос:
PATCH /tasks/{id}/status
{
    "status": "in_progress"  // или "todo", "done"
}

// Сервер обновляет:
1. Статус задачи в таблице tasks
2. Запись в таблицу task_history (с логированием изменения)
```

### Frontend (Vue.js)
```javascript
// Процесс:
1. startDrag() - начало перетаскивания (сохраняем информацию о задаче)
2. moveTask() - при drop на новую колонку
   - Оптимистичное обновление UI (сразу показываем изменение)
   - Отправляем PATCH запрос на сервер
   - При ошибке - откатываем изменения
3. getUserName() - показываем имя исполнителя
```

## 🎨 Визуальные индикаторы

### Цветовые схемы колонок
| Колонка | Цвет | Значение |
|---------|------|----------|
| К выполнению | Синий | Задача ждет начала |
| В работе | Жёлтый | Активная работа |
| Готово | Зелёный | Задача завершена |

### Карточки задач
- **Синяя полоса** - задача в "К выполнению"
- **Жёлтая полоса** - задача в "В работе"
- **Зелёная полоса** - задача в "Готово"
- **Курсор grab** - перетаскиваемая карточка
- **Opacity 0.5** - во время перетаскивания (полупрозрачная)

## 💾 Сохранение в базе данных

Когда вы перемещаете задачу:

1. **UI обновляется сразу** (optimistic update)
   ```
   Пользователь видит изменение немедленно
   ```

2. **На сервер отправляется запрос**
   ```
   PATCH /tasks/{taskId}/status
   ```

3. **В базе данных обновляется**
   ```sql
   UPDATE tasks SET status='in_progress', updated_at=NOW() WHERE id={taskId}
   ```

4. **В историю записывается запись**
   ```sql
   INSERT INTO task_history 
   (task_id, changed_by, field_name, old_value, new_value)
   VALUES ({taskId}, {userId}, 'status', 'todo', 'in_progress')
   ```

5. **При ошибке - данные восстанавливаются**
   ```
   Если запрос упал - перезагружаем задачи с сервера
   ```

## 🐛 Возможные проблемы и их решение

### Задача не переместилась
**Причина:** Ошибка сети или сервера
**Решение:** Страница автоматически перезагрузит данные, или обновите страницу (F5)

### Задача показывается в двух колонках
**Причина:** Очень редко при одновременных действиях
**Решение:** Обновите страницу (F5)

### Drag-and-drop не работает
**Причина:** Может быть проблема с браузером
**Решение:** 
- Убедитесь, что используете современный браузер (Chrome, Firefox, Safari, Edge)
- Очистите кеш браузера
- Попробуйте в инкогнито режиме
