# Scifi - Task Management System

Современная система управления задачами, вдохновленная Jira, с поддержкой Kanban доски и полного управления проектами.

## 🚀 Особенности

- ✅ **Создание и управление задачами** - полное управление жизненным циклом задач
- ✅ **Kanban доска** - визуальное управление статусами задач
- ✅ **Управление проектами** - создание и организация проектов
- ✅ **Система комментариев** - обсуждение задач в реальном времени
- ✅ **История изменений** - полный аудит всех изменений
- ✅ **Управление командой** - добавление и управление членами проекта
- ✅ **Приоритизация** - поддержка 5 уровней приоритета
- ✅ **Сроки выполнения** - отслеживание дедлайнов
- ✅ **Темная тема** - удобное переключение между светлой и темной темой

## 🛠 Технологический стек

- **Backend**: Go (Golang)
- **Frontend**: Vue.js 3 + Bootstrap 5
- **Database**: PostgreSQL
- **HTTP Framework**: Gorilla Mux
- **UI Components**: Bootstrap 5.3.0, Font Awesome 6.0.0

## 🔧 Установка

### 0. Настройка переменных окружения (ВАЖНО!)
```bash
# Скопируйте файл примера
cp .env.example .env

# Отредактируйте .env и установите свои значения
# DB_HOST=localhost
# DB_PORT=5432
# DB_USER=postgres
# DB_PASSWORD=ваш_пароль_БД
# DB_NAME=SRA
```

**⚠️ ВАЖНО:** Никогда не коммитьте файл `.env` в репозиторий!

### 2. Инициализация базы данных
```bash
# Создание таблиц
psql -h localhost -U postgres -d SRA -f db/schema.sql

# Применение миграций
psql -h localhost -U postgres -d SRA -f migrations/add_task_fields.sql
```

### 3. Установка зависимостей Go
```bash
go mod download
```

### 4. Запуск приложения
```bash
go run main.go
```

Приложение будет доступно по адресу: `http://localhost:8080`

## 🎯 Использование

### Просмотр Kanban доски

1. Перейдите в раздел **"Разделы"**
2. Выберите нужный раздел
3. Нажмите вкладку **"Доска"**
4. **Перетаскивайте задачи** между колонками для изменения их статуса:
   - **К выполнению** → **В работе** → **Готово**
5. Статус обновляется **автоматически** при перемещении

**Ключевые особенности:**
- ✅ Drag-and-drop интерфейс
- ✅ Живое обновление статуса
- ✅ История всех изменений в БД
- ✅ Отображение исполнителя на каждой карточке
- ✅ Цветовая индикация статусов

1. Нажмите кнопку **"Создать"** в верхней панели навигации
2. Заполните форму:
   - **Раздел** (обязательно) - выберите проект
   - **Тип задачи** - Задача, Баг, Функция или Эпик
   - **Статус** - К выполнению, В РАБОТЕ или ГОТОВО
   - **Резюме** (обязательно) - краткое описание
   - **Описание** - подробное описание задачи
   - **Исполнитель** - выберите или назначьте себя
   - **Приоритет** - выберите уровень (Lowest - Highest)
   - **Срок выполнения** - установите дату
   - **Дата начала** - когда начнется работа
   - **Команда** - укажите команду

3. Нажмите **"Создать"** для сохранения

### Создание проекта

1. Откройте раздел **"Разделы"** в левой панели
2. Нажмите **"Создать раздел"**
3. Выберите шаблон (Kanban, Scrum или Пустой)
4. Заполните данные проекта и пригласите членов команды

### Просмотр Kanban доски

1. Перейдите в раздел **"Разделы"**
2. Выберите нужный раздел
3. Переключитесь на вид **"Доска"**
4. Перетаскивайте задачи между колонками для изменения статуса

## 🔌 API Endpoints

### Аутентификация
- `POST /auth/register` - регистрация нового пользователя
- `POST /auth/login` - вход в систему
- `GET /logout` - выход из системы

### Пользователи
- `GET /users` - получить список всех пользователей
- `GET /me` - получить текущего пользователя
- `POST /users` - создать нового пользователя

### Проекты
- `GET /projects` - получить все проекты
- `POST /projects` - создать новый проект
- `GET /projects/{id}/tasks` - получить задачи проекта
- `POST /projects/{id}/tasks` - создать задачу в проекте
- `GET /projects/{id}/progress` - получить прогресс проекта

### Задачи
- `POST /tasks` - создать задачу
- `PATCH /tasks/{id}/status` - обновить статус задачи
- `POST /tasks/{id}/comments` - добавить комментарий
- `GET /tasks/{id}/comments` - получить комментарии

### Члены проекта
- `POST /project-members` - добавить члена в проект
- `GET /projects/{id}/members` - получить членов проекта

## 📝 Примеры API запросов

### Создание задачи
```bash
curl -X POST http://localhost:8080/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": 1,
    "title": "Исправить баг в логине",
    "description": "Пользователи не могут войти через Google",
    "status": "К выполнению",

    "created_by": 1,
    "due_date": "2026-05-20T00:00:00Z",
```

```bash

```

```bash

  -H "Content-Type: application/json" \
  -d '{"status": "В РАБОТЕ"}'
```

## 🐛 Решение проблем

### Ошибка подключения к БД
```
Cannot connect: could not connect to server
```
**Решение:** Проверьте, что PostgreSQL запущен и соединение правильно настроено в `db/db.go`

### Порт 8080 уже занят
```bash
# Измените порт в main.go
# или освободите порт:
netstat -ano | findstr :8080
taskkill /PID <PID> /F
```

### Задача не сохраняется
- Проверьте, что project_id существует в БД
- Проверьте, что таблица tasks имеет все необходимые колонки
- Выполните миграцию: `psql -h localhost -U postgres -d SRA -f migrations/add_task_fields.sql`
